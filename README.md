# Agent Security Research Navigation

A curated navigation hub for AI agent security research.

This repository organizes public resources by security domain, including general agent security, self-evolving agents, long-term memory, prompt injection, retrieval-augmented generation, tool use, Model Context Protocol, multi-agent systems, privacy, computer-use agents, supply chains, benchmarks, red teaming, and real-world incidents.

> All resources listed here are publicly accessible without mandatory account registration.

## Recommended Research Workflow

1. **Define the attack surface.**  
   Select one system component, such as memory, retrieval, tool use, inter-agent communication, user interface, or supply chain.

2. **Build the threat model.**  
   Specify the adversary, access level, attack objective, knowledge assumptions, persistence, and expected impact.

3. **Select a reproducible baseline.**  
   Prefer an open implementation with inspectable prompts, memory operations, tools, datasets, and evaluation tasks.

4. **Choose measurable outcomes.**  
   Report attack success rate, utility preservation, persistence, transferability, stealth, computational cost, and defense overhead.

5. **Use threat-informed evaluation.**  
   Include benign, adversarial, adaptive, and ablation settings, and map experiments to established attack terminology.

6. **Record reproducibility details.**  
   Document model versions, prompts, random seeds, datasets, APIs, hardware, costs, and failure cases.
